# 参赛作品提交说明

**日期**: 2026-03-28

## 提交要求

### 文件要求
- 源码文件名: `Solution.cpp` (大写 S)
- 单文件编译: `g++ -std=c++17 -O2 -o Solution Solution.cpp`
- 提交内容: 源代码压缩包 (无exe)

### 运行环境
- 评测机: Ubuntu 22.04, g++ 11.4.0
- 内存限制: 2GB
- 预处理时间: ≤ 1秒
- 总时间: ≤ 10分钟

### 交互协议

```
1. 读取 n1, n2 (多边形 A, B 的顶点数)
2. 读取 A 的 n1 个顶点坐标
3. 读取 B 的 n2 个顶点坐标
4. 读取 "OK" 字符串
5. 输出 "OK" (预处理完成)
6. 读取 m (测试点数量)
7. 读取 m 个测试点坐标
8. 读取 "OK" 字符串
9. 输出 m (结果总数)
10. 循环输出 m 个 MTV 向量 (x y 格式, 5位小数)
11. 输出 "OK" (结束)
```

### 输出格式
- 数值精度: 5位小数 (setprecision(5))
- 零值处理: 避免 -0.00000
-  flush: 每次输出后立即 flush

### 评分标准
- MTV误差 ≤ 1e-4: 满分
- 时间超限: 0分
- 格式错误: 0分

### EPS 选择
- 推荐: 1e-6 (与评测精度 1e-4 匹配)
- 过大: 可能误判重叠
- 过小: 数值不稳定

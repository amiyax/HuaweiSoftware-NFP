# 算法优化进度记录

**日期**: 2026-03-28
**当前状态**: 与 Demo 分数持平，已提交

## 已完成优化

### 1. 投影偏移优化
- 不再 translate 多边形，直接在投影值上加偏移
- 节省内存分配开销

### 2. AABB 宽相过滤
- 预处理计算两个多边形的轴对齐包围盒
- 测试时先检查 AABB 是否重叠
- 无重叠直接返回 (0,0)，跳过 SAT 计算
- **注意**: 对本测试集效果不明显（大部分用例重叠）

### 3. 避免 Normalize 函数调用
- 用 `axis = edge.Perp() * (1/sqrt(edgeLenSq))` 替代 `Normalize()`
- 减少函数调用开销

### 4. 预处理凸性检测
- 预留 convex1/convex2 变量
- 未来可用于分支优化

## 代码结构

```
Vector2D (基础向量)
    ↓
Polygon (多边形 + 中心点)
    ↓
AABB (轴对齐包围盒)
    ↓
isConvex() (凸性检测 - 预处理)
ProjectPolygon() (投影)
GenSolution() (SAT MTV)
main() (I/O)
```
